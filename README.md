Secret Rooms — это клиент-серверное Python-приложение для одноразовой и краткосрочной передачи секретной информации (пароли, токены, коды восстановления) без хранения содержимого в открытом виде на сервере и без использования сайта/браузера. Шифрование выполняется на стороне клиента (zero-knowledge для сервера), а доступ контролируется временем жизни (TTL) и числом просмотров (burn-after-read).

⸻⸻⸻⸻⸻⸻⸻⸻

Кому и зачем это полезно
	•	Разработчикам / DevOps / админам — безопасно передать временные креды: доступ к тестовому стенду, API-ключ, токен бота.
	•	Поддержке и учебным командам — разовый обмен конфиденциальными данными без «вечного следа» в чатах и почте.
	•	Маленьким командам/курсам — лёгкая альтернатива “тяжёлым” Vault-решениям, когда нужен именно эпизодический обмен.

Главная ценность: минимум «расползания» секретов (не попадают в истории чатов/бэкапы), контроль над сроком и количеством чтений, а сервер не знает содержимого.
